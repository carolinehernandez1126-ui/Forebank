# Instrucciones para el archivo de Codex

- Guardar aquí las respuestas finales sustantivas, opiniones, propuestas y correcciones de Codex para que otros colaboradores puedan revisarlas.
- Fechar en America/Bogota, usar nombres cronológicos y actualizar el índice README.md. No inventar timestamps precisos ni revisiones de Claude.
- Mantener el historial: corregir mediante un registro nuevo y marcar el anterior como sustituido. No borrar errores históricos para aparentar que nunca existieron.
- Distinguir hechos verificados, opinión, hipótesis, decisión y faltantes. Referenciar la evidencia y la versión del plan cuando aplique.
- El texto público puede contener un resumen saneado de una respuesta si incluye información privada; identificar la omisión. Nunca publicar tokens, .env, saldos actuales, posiciones, órdenes reales ni diarios privados.
- Las copias de contexto describen la implementación local. No afirmar que el código completo está publicado o que una estrategia está validada por existir este archivo.
- Autenticarse como jsforeroc80-debug; propietario real del repo carolinehernandez1126-ui. Preservar archivos ajenos y usar actualizaciones sin force-push.
