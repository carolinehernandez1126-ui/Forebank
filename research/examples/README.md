# Demostración reproducible

Estos archivos proceden de `lab demo`: datos generados con semilla 42, fechas fijas y símbolo DEMO/USD. No corresponden a un activo real ni a una recomendación.

La demo mantiene `synthetic=true` y `RESEARCH_ONLY`. La política impide aprobar operaciones usando ese dataset. Las cifras del baseline no tienen valor predictivo; sirven para comprobar instalación, flujo de análisis y contratos.

Los snapshots reales descargados para comprobar conectores se mantienen en `data/` y los reportes en `outputs/`, ambos fuera de Git.
