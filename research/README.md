# Resultados compartidos

Esta carpeta es la zona publicable del laboratorio. Usar una subcarpeta por hipótesis/experimento y conservar tanto resultados positivos como negativos.

Plantillas: HYPOTHESIS_TEMPLATE.md, TRADE_PLAN_TEMPLATE.md, REVIEW_TEMPLATE.md y EXECUTION_TEMPLATE.md. Los JSON operativos deben ajustarse a schemas/. No publicar saldos, claves, IDs de cuenta, detalle de órdenes reales ni payloads de proveedores sin revisar licencias. Cantidades públicas preferiblemente normalizadas; cada operador necesita un gate privado para su cuenta.

`examples/` contiene solo informes de demostración sintéticos. No hay todavía propuestas de trades reales ni revisión real de Claude.
